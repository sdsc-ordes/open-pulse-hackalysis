## Usage

### Extract Hackathon Data

Extract data from LauzHack:
```bash
just hackalysis --output_folder ./data --hackathon_provider lauzhack
```

Extract data from Devpost:
```bash
just hackalysis --output_folder ./data --hackathon_provider devpost
```
